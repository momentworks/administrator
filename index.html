서버(구글시트) 연결

구글 시트를 무료 서버처럼 연결하면, 이 페이지를 어디서 열어도 같은 데이터를 계속 불러오고 저장할 수 있어요. 아래 순서대로 한 번만 설정하면 돼요.

  1. 새 구글 시트를 하나 만드세요 (아무 이름이나 상관없어요)
  2. 상단 메뉴 확장 프로그램 → Apps Script 클릭
  3. 기존 코드를 지우고 아래 코드를 붙여넣기
  4. 우측 상단 배포 → 새 배포 → 유형: 웹 앱 선택
    실행 계정: 나 / 액세스 권한: 모든 사용자 로 설정 후 배포
  5. 발급된 웹 앱 URL을 복사해서 아래에 붙여넣고 저장
